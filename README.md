# TER Serious Game

## Description

Ce projet est un serious game développé avec Unity dans le cadre du TER.

## Prérequis

* Unity 6 (ou la version utilisée pour le projet)
* Git
* Git LFS (si nécessaire pour les fichiers volumineux)

## Installation

1. Cloner le dépôt :

```bash
git clone https://github.com/votre-utilisateur/votre-depot.git
```

```bash
git lfs pull
```

2. Ouvrir le projet avec Unity Hub.

3. Sélectionner la version Unity recommandée.

4. Attendre l'importation complète des assets.

## Exécution

### Depuis Unity

* Ouvrir la scène principale Project -> Assets -> Prefabs -> Scenes -> "Game" ou "Main Menu"
* Cliquer sur le bouton Play.

### Depuis la version compilée

* Lancer le fichier `Setup.exe` ou `Game.exe`.
* Suivre les instructions d'installation si nécessaire.
